真实能力、参数与验证边界

如何同步

  1. 使用 Chrome 或 Edge，通过 localhost 或 HTTPS 打开本页。
  2. 先断开手机 App 与码表的蓝牙连接，保持码表开机、蓝牙开启。
  3. 点击连接，选择 BSC500，再读取目标骑行模式。首次读取会替换示例方案。
  4. 调整数据页，点击同步，检查修改并确认。同步会先备份，再写入，最后重新读取核对。

读取优先使用 ATT 有响应写入，以获取底层确认或权限错误。若出现系统蓝牙配对提示，请在电脑和码表上确认正常配对，不需要解除手机 App 的账号绑定。系统确认阶段最多等候 45 秒，随后另等候 12 秒页面回复。工具无法直接报告当前链路是否加密。

连接时按官方 App 初始化 9e、8e、7e、6e 四个已知通知通道。页面命令仍仅使用 9e，其他通道只旁路记录通知，不发送命令，也不混入页面解析。可选通道缺失或订阅失败会记录原因。

心率分布、速度仪表、功率等图形字段使用 APK 内置预览图片，并按格子尺寸选择素材、等比显示。图片保留原色，不随深浅色主题反色；手机新版下发的素材和真机画面可能不同。图形与读数均为固定示例，不代表实时数据。普通数据页按设备的 graphic_display 位决定哪一格画图（真机 16 页与官方两次写入报文均已核对），字段或版式变化时网页会重算该位；专项页保留设备原值。

目前确认到了哪一步

官方 iPhone App 与 V1.08.005 真机抓包已确认页面读写、字段 ID 与成功回执。本网页实现了相同的消息头、CRC、Protobuf 与分片通道；浏览器直连仍需真机验证，若设备要求官方会话握手，不会尝试猜测或绕过。

仅使用 APK 提供的原厂版式。不支持自定义字体、任意坐标或把网页绘制效果安装到固件。深浅色切换仅用于预览。模式编号 0–9 来自协议范围，设备是否启用某一模式以读取结果为准。

同步失败怎么办

设备回执成功不等于页面已正确保存。若读回不同、超时或断连，请先重新读取并核对设备屏幕，不要连续重试写入。可导入自动下载的备份，在重新读取设备后确认恢复。

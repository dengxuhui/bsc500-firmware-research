# BSC500 V1.04.003 与 V1.08.005 对比调查

调查日期为 2026 年 11 月 25 日。iGPSPORT App 的「固件检测」页面显示 `V1.08.005` 新增路线颜色自定义。升级后，设备日志确认主程序已切换到 `V1.08.005`，Boot 版本随后从 `112` 变为 `114`。逐字节对比 USB 文件发现，导航配置 `cfg_navi` 的值只有一位变化，具体用途还需通过单项设置实验验证。新版升级包尚未取得，包内文件和绘制函数的改动仍待确认。

## 样本与范围

| 样本 | 来源 |
| --- | --- |
| App 更新提示 | 用户提供的 `截图/IMG_8768.PNG`。同批其余 10 张为「当前方案」页面，可用于参考数据字段和骑行页面布局。 |
| 旧版固件 | 厂商公开接口提供的 `V1.04.003` 原厂 RSC，共 4,514,804 字节。重新解包后，6 个条目的 SHA-256 均与仓库清单一致。 |
| 旧版 USB 备份 | `.local/usb-copy/`。以旧备份的 28 个文件为比较基线。 |
| 新版 USB 卷与本地快照 | `/Volumes/BSC500`。比较范围为根目录的 `Device.bin`、`resource/`、`iGPSPORT/Settings/` 和 `iGPSPORT/System/`。设置库和设备日志留存在 `.local/usb-v1.08.005.91zCom/`。 |

最初重连时，macOS 的 USB 设备树和磁盘列表均未出现码表。后来系统识别出 `BSC500 Mass Storage`，将约 30 GB 的 FAT32 卷挂载到 `/Volumes/BSC500`，随后才取得新版样本。比较使用只读文件访问。

## 路线颜色的设置线索

| 设置键 | 两版值长 | 值内偏移和差异 |
| --- | ---: | --- |
| `cfg_navi` | 16 字节 | `0x08` 从 `DE` 变为 `DF`，仅最低位改变。两份快照的文件偏移均为 `0x0F39`。 |
| `cfg_display` | 76 字节 | `0x04` 从 `04` 变为 `11`。从 `0x0C` 开始的 16 色色板逐字节相同。 |
| `cfg_sound` | 8 字节 | `0x02` 从 `00` 变为 `02`，`0x05` 从 `00` 变为 `01`。 |

新版日志第 35,183 行显示 `cfg_navi` 在关机过程中保存成功。日志未记录触发写入的具体选项，现有快照也未控制颜色以外的变量，因此 `0x08` 仍是候选偏移。新版日志里出现了 `NaviRouteDetail` 页面，旧版 `BSC500_APP.bin` 在文件偏移 `0x3F0969` 已包含 `NaviRouteDetail.cpp` 路径字符串，单凭页面名无法定位新增的绘制代码。 [旧版设置注册表](../native/settings-registry.json)

## 固件升级证据

新版快照的 `device_log.txt` 保留了本次升级的记录。

| 日志行号 | 记录 |
| --- | --- |
| 32,668 | 接收路径为 `0:/BSC500.rsc.tmp`，声明大小为 5,565,852 字节。 |
| 33,488、33,619 | `asset_decode_update_app` 开始执行并记录 `ret:1`，之后设备重启。 |
| 33,673–33,676 | 首次记录新版主程序 `108005`（`V1.08.005`），此时 Boot 版本仍为 `112`。 |
| 33,864–33,867 | 后续启动记录 Boot 版本 `114`，主程序版本仍为 `108005`。 |

调查时，App 提示的是 `V1.08.005`，公开固件接口返回的是 `V1.04.003`。升级后的 USB 用户卷未找到新版 RSC 或 `BSC500_APP.bin`。日志能确认主程序和 Boot 的版本变化，Boot 对应的包内条目及更新机制尚未从包内容验证。

## 待验证项

1. **颜色设置落盘位置。** 用同一台 `V1.08.005` 码表，只修改路线颜色，分别保留颜色 A、颜色 B、改回颜色 A 后的 `kvlist_fs.bin`。以随颜色切换并可复原的值作为候选，再用同一路线检查屏幕实际颜色。
2. **新版 RSC 的文件清单。** 取得官方新版包后，记录包大小和 SHA-256，再用仓库的解包脚本与旧版清单按文件名和条目哈希对比，逐项列出新增、删除和修改。
3. **路线颜色绘制函数。** 用单项设置实验定位的字段和旧版导航页面字符串作为线索，在两个主程序镜像中追踪设置读取、颜色选择和绘制调用。 [RSC 解包脚本](extract_rsc.py)
